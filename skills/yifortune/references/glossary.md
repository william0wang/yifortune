# YiFortune Glossary

The single source of truth for fortune-telling terminology and mapping tables. All other `` skills reference this instead of redefining terms.

## Core BaZi Terms

| Term                          | Chinese        | Meaning                                                                                                                                                                                                             |
| ----------------------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Day Master                    | 日主           | The heavenly stem of the DAY pillar — represents the self. Everything is read relative to it.                                                                                                                       |
| Four Pillars                  | 四柱           | Year/Month/Day/Hour pillars (年柱/月柱/日柱/时柱), each = 1 heavenly stem + 1 earthly branch.                                                                                                                       |
| Ten Gods                      | 十神           | Ten relationship archetypes derived from the day master vs. other stems/branches: 正官/七杀 (authority), 正印/偏印 (resource/knowledge), 比肩/劫财 (peer/rival), 食神/伤官 (expression/talent), 正财/偏财 (wealth). |
| Hidden Stems                  | 藏干           | Stems hidden inside each earthly branch (主气 main / 中气 middle / 余气 residual). Add depth to a pillar.                                                                                                           |
| Luck Pillars                  | 大运           | Ten-year life phases. Each has its own stem-branch that interacts with the natal chart. Computed differently for male (forward) vs female (backward).                                                               |
| Annual/Monthly/Daily Pillar   | 流年/流月/流日 | The current year/month/day's stem-branch — used in period-fortune and timing analysis.                                                                                                                              |
| Favorable/Unfavorable Element | 用神/喜神/忌神 | The element(s) that bring balance to the chart (favorable) vs. those that disrupt it (unfavorable). The root judgment for timing, career, health, etc.                                                              |
| Day Master Strength           | 身旺/身弱      | Whether the day master is well-supported (身旺) or weak (身弱) across the chart. Determines what the person can "handle" (e.g. 身旺 can bear heavy 财 wealth; 身弱 cannot).                                         |
| Structure/Pattern             | 格局           | The dominant pattern of the chart (正官格, 七杀格, 食神格, 伤官格, 正财格, 偏财格, 正印格, 偏印格, etc.). Sets the life theme.                                                                                      |
| Stars (Shen Sha)              | 神煞           | Symbolic stars overlaid on the chart (桃花 romance star, 驿马 travel star, 天乙 noble helper, 文昌 academic star, 空亡 void, etc.).                                                                                 |
| Spouse Palace                 | 夫妻宫         | The DAY branch — represents the marriage/partner dimension.                                                                                                                                                         |
| Spouse Star                   | 配偶星         | The star representing the partner: 财星 for males, 官杀 for females.                                                                                                                                                |

## 刑冲合会 (Clashes, Combinations, Punishments)

These describe how stems/branches interact — the dynamism engine of a reading:

| Term             | Chinese        | Meaning                                                                                                            |
| ---------------- | -------------- | ------------------------------------------------------------------------------------------------------------------ |
| Clash            | 冲             | Opposing branches (子午冲, 卯酉冲, etc.) — conflict, sudden change, instability.                                   |
| Combination      | 合 (六合/三合) | Harmonious branch pairings (六合) or trines (三合 申子辰/亥卯未/寅午戌/巳酉丑). Brings cohesion, help, connection. |
| Punishment       | 刑             | Friction/grief between branches (寅巳申三刑, 子卯刑, etc.). Internal tension, legal/health trouble.                |
| Harm             | 害             | Covert damage between branches (子未害, etc.). Hidden friction, betrayal.                                          |
| Stem Combination | 天干合         | Five harmonious stem pairs (甲己合, 乙庚合, etc.) — attraction, alliance, transformation.                          |
| Stem Clash       | 天干冲         | Four opposing stem pairs (甲庚冲, 乙辛冲, etc.) — direct confrontation.                                            |

## Western Astrology Terms

| Term                   | Meaning                                                                                                                                                |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| The Big Three (三巨头) | Sun (太阳 — core identity), Moon (月亮 — emotional needs), Ascendant/Rising (上升 — outward persona).                                                  |
| Midheaven (MC)         | The 10th house cusp — career direction and public role.                                                                                                |
| Houses (宫位)          | 12 life areas. Key: 2nd (income), 4th (home/family), 5th (romance/creativity), 6th (daily work), 7th (partnership), 10th (career).                     |
| Aspects (相位)         | Angular relationships between planets. Major: 合相 conjunction (0°), 六合 sextile (60°), 刑相 square (90°), 三合 trine (120°), 冲相 opposition (180°). |
| Signs by Element       | Fire (白羊/狮子/射手), Earth (金牛/处女/摩羯), Air (双子/天秤/水瓶), Water (巨蟹/天蝎/双鱼).                                                           |

## I Ching Terms

| Term                          | Chinese   | Meaning                                                                                              |
| ----------------------------- | --------- | ---------------------------------------------------------------------------------------------------- |
| Hexagram                      | 卦 / 卦象 | A 6-line figure, each line yin (broken) or yang (solid). 64 total.                                   |
| Changing Line                 | 动爻      | A line that transforms (yin↔yang), producing the Transformed Hexagram. The key to a dynamic reading. |
| Original/Transformed Hexagram | 本卦/变卦 | The cast hexagram (本) vs. the hexagram after changing lines flip (变).                              |
| Hexagram Text                 | 卦辞      | The authoritative text for each hexagram (元/亨/利/贞 judgments + 象 imagery).                       |
| Line Text                     | 爻辞      | The text for each individual line — key when 动爻 exist.                                             |

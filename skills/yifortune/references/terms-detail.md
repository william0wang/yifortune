## 西方星座 (Western Zodiac) — Element & Compatibility

| Element | Signs                    | Core quality                      |
| ------- | ------------------------ | --------------------------------- |
| Fire    | Aries, Leo, Sagittarius  | Vitality, passion, action         |
| Earth   | Taurus, Virgo, Capricorn | Practicality, structure, patience |
| Air     | Gemini, Libra, Aquarius  | Communication, intellect, social  |
| Water   | Cancer, Scorpio, Pisces  | Emotion, intuition, depth         |

**Compatibility ranking** (by element + modality):

- **Best**: same element (Fire↔Fire) or complementary element (Fire↔Air, Earth↔Water)
- **Good**: sextile/trine aspects (signs 60°/120° apart)
- **Needs work**: square (90°) or opposition (180°) — growth through friction

## 纳音 (Nayin / Melodic Element)

Each 60-cycle stem-branch pair carries a "melodic element" (e.g. 甲子乙丑海中金 = "Gold in the Sea"). Used in name analysis (五格剖象法) and as supplementary flavor. Not a primary analysis axis — cite it only when relevant.

## 胎元 / 命宫 / 身宫 (Auxiliary Pillars)

- **胎元 (Fetal Origin)**: represents the prenatal influence / genetic foundation.
- **命宫 (Life Palace / Own Sign)**: represents the life-direction / overarching theme.
- **身宫 (Body Palace)**: represents physical vitality and mid-late life focus.

## 五格剖象法 (Five-Grid Name Method)

Used in name analysis. Five grids derived from Kangxi-dictionary stroke counts:

| Grid            | Derived from                      | Represents                        |
| --------------- | --------------------------------- | --------------------------------- |
| 天格 (Heaven)   | Surname strokes + 1               | Ancestral / inherited background  |
| 人格 (Human)    | Surname last + given first stroke | Core personality (most important) |
| 地格 (Earth)    | Given name strokes total          | Early life (1-34 yrs)             |
| 外格 (External) | Total − 人格                      | Social / external relations       |
| 总格 (Total)    | All strokes combined              | Late life (35+ yrs) / overall     |

Each grid's stroke count maps to an element and a fortune verdict (大吉/吉/凶).

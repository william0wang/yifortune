# YiFortune Career Reading

Career-focused analysis building on the BaZi chart. Call `get_bazi` (or reuse a prior chart), then apply the career lens below. For the chart's structural reading, consult **bazi-chart**; for terminology, consult **glossary**.

## Data Source

Call `get_bazi` with the user's birth data. Read: 日主 strength, dominant 十神, 大运 sequence, 用神/喜神, and 刑冲合会. If the user also has an astrology chart, cross-reference MC (10th house) and Saturn placement for career direction via the **astrology-chart**.

## Analysis Framework

### Work Style — Day Master Strength

- **身旺** (strong): suits challenge, entrepreneurship, competitive environments. Can bear pressure and lead.
- **身弱** (weak): suits teamwork, accumulation, stable platforms. Thrives with support (印星/比劫).

### Career Direction — Ten Gods

| Dominant 十神     | Career talent                                                    |
| ----------------- | ---------------------------------------------------------------- |
| 官杀 (authority)  | Management, government, law, military, structured organizations  |
| 印星 (resource)   | Research, academia, education, specialized knowledge, advisory   |
| 食伤 (expression) | Creative industries, media, arts, consulting, entrepreneurship   |
| 财星 (wealth)     | Business, finance, trade, sales, operations, resource management |
| 比劫 (peer)       | Execution, partnerships, team sports, competitive fields         |

### Industry Direction — Five-Element Mapping

Match the 用神 (favorable element) to industries. See **glossary** mapping-tables.md for the full element → industry table. Provide ≥3 suited industries with reasoning.

### Career Timing — Luck Pillars (大运)

- Favorable-element 大运 → career growth window (promotions, expansion)
- 忌神 大运 → consolidation phase (build skills, don't overextend)
- 大运 transitions → major career pivot points
- For specific timing (e.g. "should I change jobs this year?"), cross-reference with 流年

### Workplace Dynamics

- **With superiors**: 官杀旺 → thrives under authority/hierarchy; 食伤旺 → prefers autonomy; needs a hands-off boss
- **Best team role**: 比劫旺 → team leader/coordinator; 印星旺 → strategist/advisor; 食伤旺 → innovator/spokesperson
- **Conflict zones**: based on 刑冲合会 in the chart — which personality types to avoid or manage carefully

### Entrepreneurship vs. Employment

- 食伤 + 财星旺 → entrepreneurial (creates and monetizes)
- 官杀 + 印星旺 → institutional (thrives within structure)
- 比劫旺 alone → partnership-oriented (needs co-founders)

## Output

Two layers (see SKILL.md — the plain layer is mandatory and always last):

**Inner layer (命理要点 — for traceability, compact, terms OK):**

1. **职业天赋总论** — work style + top talent clusters
2. **适合领域** — ≥3 industries with element + ten-god reasoning
3. **职业时机** — current 大运 + upcoming windows for moves
4. **职场建议** — workplace dynamics + best role + conflict management
5. **创业/就业** — which path suits the chart better and why

**Outer layer (大白话总结 — for the user, always last, no raw jargon):**

6. **一句话说说你适合干什么** — the user's work nature in their own register (e.g. "你是靠手艺和专业吃饭的人，不太适合在人情世故太重的地方混")
7. **最推荐的方向** — name 1-2 industries/roles in plain words, with a one-sentence why ("教育、内容、咨询这类把知识输出给别人做的事，跟你最搭")
8. **接下来该考虑的事** — concrete next-step, mapped to timing (e.g. "今年是动一动的好时机，明年下半年之后会更稳，可以现在开始铺路")

## If the user is torn over a specific decision

When the question shifts from "我适合干什么" (pattern) to "这件具体的事该不该做" (a yes/no) — 接 offer、跳槽、合伙、转行 — BaZi sets the backdrop but **a Yijing cast cuts through the decision more directly**. Offer it proactively:

> "你是该往管理方向走这个八字看得很清楚。但你现在纠结的这个具体 offer 要不要接，我帮你起一卦看会更准——随便说一句话或几个词给我都行，想到什么说什么。"

See **yijing-cast** for the casting + reading flow.
